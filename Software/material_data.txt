----------------------
Material Data Configs.
----------------------
BEGIN INSTRUCTIONS
1) Read the variable descriptions below:
	rho: 		density, 				kg/m^3
	cp: 		specific heat at constant pressure, 	J/(kg-K)
	T_melt: 	melting temperature, 			K
	E:		elastic modulus, 			Pa
	CTE:		coefficient of thermal expansion, 	K^-1
	epsilon:	surface roughness, 			m
	k:		thermal conductivity vs. temperature,	W/(m-K) vs. K
	sigma_y:	yield stress vs. temperature,		Pa vs. K

2) To add a new config., copy the format below. Temperature-dependent
	properties are evaluated using linear interpolation with coefficients
	in a matrix with rows of the form [T, value] (No spaces inside the
	brackets- the config reader splits lines on spaces). Reading for a
	value for a temperature outside the table's T range results in an
	error.

\EXAMPLE\
rho = <value>
cp = <value>
T_melt = <value>
E = <value>
CTE = <value>
epsilon = <value>
k = [<T1>,<value1>;<T2>,<value2>]
sigma_y = [<T1>,<value1>;<T2>,<value2>]
\END\

3) Separate configs. as shown below

\CONFIG1\
<properties>
\END\

\CONFIG2\
<properties>
\END\

END INSTRUCTIONS

\END\
