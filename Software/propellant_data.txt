------------------------
Propellant Data Configs.
------------------------
BEGIN INSTRUCTIONS
1) Read the variable descriptions below:
	name:		propellant name,			~
	phase:		<"LIQUID", "GAS">,			~
	type:		<"OXIDIZER", "FUEL">,			~
	cost:		cost per unit mass,			USD/kg
	MW:	        molar weight,				kg/mol
	T_crit:		critical temperature,			K
	P_crit:		critical pressure,			Pa
	rho_crit:	critical density,			kg/m^3
	rho: 		density, 				kg/m^3
	cp: 		specific heat at constant pressure, 	J/(kg-K)
	k:		thermal conductivity, 			W/(m-K)
	mu:		dynamic viscosity,			Pa-s
	p_vap:		vapor pressure,				Pa

2) To add a new config., copy the format below. A property (rho, cp, k, mu, p_vap) is
	either a constant number, or a correlation. For a correlation, set the property to
	"correlation" and add two more lines, <property>_model and <property>_coeffs. The model
	is the name of one of the correlation models implemented in Propellant.m, and the coeffs
	are that model's coefficients as a row vector or matrix. NO SPACES inside the brackets
	(the config reader splits lines on spaces). Every model's coefficient layout is
	documented in the header of its method in Propellant.m and summarized here:

	"rackett"		rho(T), Rackett equation
				[Zc]
	"assael_ethanol"	k(T, rho), Assael et al. 2010 (J. Phys. Chem. Ref. Data)
				[lambda0 numerator, 6 coeffs, Tr^0..Tr^5,
				 lambda0 denominator, 3 coeffs, Tr^0..Tr^2,
				 B1, 5 coeffs, B2, 5 coeffs,
				 critical enhancement: amplitude, offset, exponent coeff]
	"sotiriadou_ethanol"	mu(T, rho), Sotiriadou et al. 2023
				[b0..b5, c0, c1, epsilon/k_B, sigma, d0..d6, d7, d8, e1, e2]
	"antoine"		p_vap(T), piecewise Antoine equation (T in K, bar -> Pa)
				one row per valid temperature range: [T_low, T_high, A, B, C]
	"table"			any property, linear interpolation, one row per point: [T, value]

	If a property depends on tabulated values stored in an .xlsx file instead, set it to
	"<filename>" as before (see GetConfigData.m).

\EXAMPLE\
name = <value>
phase = <value>
type = <value>
cost = <value>
MW = <value>
T_crit = <value>
P_crit = <value>
rho_crit = <value>
rho = "correlation"
rho_model = "<model name>"
rho_coeffs = [<values>]
cp = <value>
k = <value>
mu = <value>
p_vap = <value>
\END\

3) Separate configs. as shown below

\CONFIG1\
<properties>
\END\

\CONFIG2\
<properties>
\END\

END INSTRUCTIONS
